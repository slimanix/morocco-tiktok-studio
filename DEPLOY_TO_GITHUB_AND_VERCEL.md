# 🚀 How to Deploy Your Autonomous TikTok Studio to GitHub & Vercel (100% Free)

This setup allows your channel to run **24/7 in the cloud** with **zero PC dependency** and a **live web dashboard on Vercel**!

---

## 🛠️ Step 1: Push Your Code to GitHub (Takes 1 Minute)

Open your terminal in `C:\Users\elidr\.gemini\antigravity\scratch\morocco_tiktok_pipeline` and run:

```powershell
# 1. Initialize git
git init
git add .
git commit -m "Initial commit of Moroccan TikTok Autonomous Studio"

# 2. Create a new repository on github.com (e.g. 'morocco-tiktok-studio')
# 3. Link and push to GitHub:
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/morocco-tiktok-studio.git
git push -u origin main
```

---

## ☁️ Step 2: Connect to Vercel for Your Live Dashboard (Takes 30 Seconds)

1. Go to **[vercel.com](https://vercel.com)** and log in with your GitHub account.
2. Click **Add New...** ➡️ **Project**.
3. Select your repository (`morocco-tiktok-studio`) and click **Deploy**.
4. **Done!** Vercel gives you a live public URL (e.g., `https://wa3ibadlah.vercel.app`) with your dashboard!

---

## 🤖 Step 3: How It Operates Completely in the Cloud

1. **Automatic Daily Trigger:**  
   GitHub Actions will wake up automatically at **20:30 (Morocco Time)** every day, scrape news, render the video, and post to TikTok.
2. **Trigger From Your Phone Anytime:**  
   Open GitHub on your phone ➡️ Go to **Actions** ➡️ Select **Moroccan TikTok Autonomous Factory** ➡️ Click **Run Workflow** to produce and post a video immediately!
3. **Download Video Backups:**  
   Every video generated in the cloud is automatically saved in GitHub's **Artifacts** tab for 7 days so you never lose a file.
