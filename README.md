# Moroccan Political Simulation Content Engine & TikTok Pipeline

This project automates the creation of satirical and explanatory political simulation TikToks in Moroccan Darija (الدارجة المغربية).

## Core Concepts
1. **The Format:** A simulated dialogue between "المواطن" (The Citizen) and "المسؤول / الوزير" (The Politician/Official).
2. **Language:** Natural Moroccan Darija with relatable humor and punchy pacing.
3. **Audio:** High-quality Moroccan Arabic neural TTS (`ar-MA-JamalNeural` for the official, `ar-MA-MounaNeural` or alternate pitch for the citizen).
4. **Length:** 30–50 seconds (optimal for 100% completion rate).

## Structure
- `scripts/`: Generator scripts and viral prompt templates.
- `output/`: Generated audio, captions, and videos.
